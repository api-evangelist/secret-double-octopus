# Secret Double Octopus (SDO)

> Secret Double Octopus (SDO) is an enterprise workforce authentication company that eliminates all user-managed passwords across an organization. Its Octopus Authentication Platform delivers phishing-resistant, passwordless MFA everywhere — including legacy, on-prem, and air-gapped systems that other passwordless solutions cannot cover. SDO's patented ZeroPassword™ technology replaces directory and legacy credentials with machine-generated ephemeral tokens, so no passwords exist on the backend and no costly redesign is required.

## What SDO does

- Provides passwordless, phishing-resistant multi-factor authentication (MFA) for the enterprise workforce.
- Covers the entire environment: SaaS, web apps, on-prem, legacy apps, VPN, RDP, VDI/Citrix, Linux SSH, shared workstations, servers, and air-gapped systems.
- Integrates out of the box with existing identity infrastructure (Active Directory, Microsoft Entra ID, Okta, and more) with no redesign.
- Supports any authenticator: mobile push, biometrics/facial, FIDO2 security keys, smart cards, Windows Hello, and OTP tokens.

## Key definitions

- **ZeroPassword™**: SDO's patented approach to true passwordless authentication. Instead of users setting and managing credentials, secrets are generated by an algorithm as ephemeral, machine-generated tokens that automatically rotate. This removes user-managed passwords across every resource, including systems that still require a password on the backend, making authentication phishing-resistant and brute-force-resistant by design.
- **Passwordless MFA vs. ZeroPassword™**: Standard "passwordless" MFA improves user experience but often leaves static passwords in place on legacy and domain-joined systems. ZeroPassword™ removes user-managed credentials entirely across legacy and modern systems, is phishing-resistant by design, and is AI-ready and compliance-ready.
- **Octopus Authentication Platform**: SDO's product that delivers ZeroPassword™ across the enterprise.
